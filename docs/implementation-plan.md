# 実装計画

## 目的
- 風船ゲームの改善内容を、事前に計画として残し、承認後に実装できるようにする。

## 管理方針
- 変更前にここに内容を記載する。
- 承認が得られた内容のみ実装する。
- 実装後は履歴ファイルに記録する。

## 現在の承認待ち項目
1. 風船の重なり時に、1回のタッチで1つだけ反応するようにする
   - 期待動作: 風船が重なっていても、1回のタッチで1つだけ割れる
   - 影響範囲: タッチイベント、風船の選択処理
   - 状態: 完了

2. 黒い風船のゲームオーバー演出をより分かりやすくする
   - 期待動作: ゲームオーバー時にメッセージ、音、アニメーションが自然に見える
   - 影響範囲: オーバーレイ表示、音声再生、アニメーション
   - 状態: 完了

3. トップページ（ゲーム選択画面）を追加する
   - 期待動作: 複数ゲームから選択できるトップページを用意し、各ゲームは `games/<name>.html` で管理される
   - 影響範囲: ルート `index.html` の差し替え、`games/` ディレクトリ構成の追加、既存ゲームファイルの移動
   - 実装手順:
     1. `index.html` をトップメニューに置き換える（案をここに記載）
     2. 既存の風船ゲームを `games/balloon.html` として保存する
     3. 動作確認・レスポンシブ確認
   - 状態: 完了

4. 4歳向け「おかいものゲーム」を追加する
   - 期待動作: 画面上部に問題文が表示され、商品をタップして買い物かごに入れ、正解ならキラキラ演出と音声で褒められる
   - 主要仕様:
     - タイトル画面に「おかいものゲーム」と「スタート」ボタンを表示する
     - 問題は「りんごを 2こ かってね！」のような形式で出す
     - 商品はりんご・バナナ・にんじん・パン・牛乳・いちごなどを大きく並べる
     - 商品をタップすると買い物かごに入る
     - 正解時は「せいかい！」、ピッ♪、レジのアニメーションを表示する
     - 1問正解ごとにコインを1枚獲得する
     - 5問ごとにレベルアップし、難易度を少し上げる（1個→2個→3個、商品種類増加）
     - ゲームオーバーなし、何度でも遊べる
     - スマホ縦画面に最適化し、パステルカラーと大きいボタンで見やすくする
     - HTML・CSS・JavaScriptを分けて実装する
   - 影響範囲: 新規 `games/shopping.html`、必要に応じてトップページのリンク追加
   - 状態: 完了

5. 「数字をならべよう」ゲームを追加する
   - 期待動作: 難易度選択画面から 3 / 5 / 10 枚を選び、数字カードをランダム配置し、1 から順番にタップして並べる。並べた順番は再生ボタンで読み上げられ、間違えても自動終了せず、正しい順番で全件揃えばクリア演出と「せいかい！」を再生する。
   - 影響範囲: 新規 `games/numbers.html` / `games/numbers.css` / `games/numbers.js`、トップページからのリンク追加、既存ゲームの変更なし
   - 状態: 実装中


6. 数字ゲームの難易度選択画面を、4歳児向けのポップなゲーム選択カードに再デザインする
    - 期待動作: 3枚の難易度カードがそれぞれゲーム内容が一目で分かる見た目になり、固定の「5」などの教材風の数字表示を使わない
    - 影響範囲: `games/numbers.html` / `games/numbers.css` のみ、ゲームロジックは変更しない
    - 状態: 実装完了

7. 5つ目のゲーム「まちがいさがし」を追加する
   - 期待動作: トップページから独立したゲームとして起動し、モード選択画面から「くらべて みつけよう」と「おぼえて みつけよう」の2つを遊べる
   - 主要仕様:
    - 新規ファイル `games/difference.html` / `games/difference.css` / `games/difference.js` を追加する
    - `index.html` にゲームカードを1つ追加し、`games/difference.html` へ遷移できるようにする
    - モード1では左右の絵を見比べ、あらかじめ定義した割合座標の正解範囲をタップして違いを見つける
    - モード2では3秒間表示した絵を隠し、少し変化した絵を見て正解範囲をタップして違いを見つける
    - 判定は画像比較ではなく、問題データ内の `x` / `y` / `radius` を割合で管理し、表示サイズに応じてタップ位置も割合変換して照合する
    - 最初はプレースホルダー画像または仮画像で1問のみ実装し、あとから素材差し替えしやすい構造にする
    - 正解時は短い演出とマーカー表示、誤答時は軽いフィードバックのみで再挑戦可能にする
    - クリア後は「もう一回」でモード選択へ戻る
   - 影響範囲: 新規 `games/difference.html` / `games/difference.css` / `games/difference.js`、`index.html`、必要に応じてテスト追加
   - 状態: 実装完了
