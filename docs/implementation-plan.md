   - 状態: 完了

   - 期待動作: 複数ゲームから選択できるトップページを用意し、各ゲームは `games/<name>.html` で管理される
   - 影響範囲: ルート `index.html` の差し替え、`games/` ディレクトリ構成の追加、既存ゲームファイルの移動

4. 4歳向け「おかいものゲーム」を追加する
   - 期待動作: 画面上部に問題文が表示され、商品をタップして買い物かごに入れ、正解ならキラキラ演出と音声で褒められる

     - タイトル画面に「おかいものゲーム」と「スタート」ボタンを表示する
     - 問題は「りんごを 2こ かってね！」のような形式で出す

     - 5問ごとにレベルアップし、難易度を少し上げる（1個→2個→3個、商品種類増加）
     - ゲームオーバーなし、何度でも遊べる
     - スマホ縦画面に最適化し、パステルカラーと大きいボタンで見やすくする
     - HTML・CSS・JavaScriptを分けて実装する
   - 影響範囲: 新規 `games/shopping.html`、必要に応じてトップページのリンク追加
