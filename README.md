# ChildGames
子供のためのゲーム

## 開発ルール
- 変更内容ごとに、まず実装計画を立てる
- その内容を `docs/implementation-plan.md` に記録する
- ユーザー承認を得てから実装を始める
- 実装後は `docs/implementation-history.md` に履歴として残す
- 変更のたびに、計画・承認・実装・履歴の流れを守る

## 主要ファイル
- `index.html`: トップページ
- `games/balloon.html`: 風船ゲーム
- `docs/implementation-plan.md`: 実装計画
- `docs/implementation-history.md`: 実装履歴

## コミット・プッシュについて
- コミットとプッシュのタイミングは、ユーザーから指示があるまで待つ
- 変更内容をまとめてコミットし、必要に応じてリモートへプッシュする
- その際も、実装計画と履歴の更新状況を確認する
